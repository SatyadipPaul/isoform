What this gate proves

Each row is a way the port could have silently broken.

Silhouette
Every part built through the registry, not by hand. A wrong geometry argument shows up as a changed outline.
Material cache
Hundreds of FINISH.* calls collapse onto the counter above. If tinting still works, roles are tagged correctly.
Geometry cache
Parametric primitives are memoised. Two service tiles must share geometry and still animate independently.
Surface presets
Vent perforation, corrugation, shutter ribs and brick bond are cache keys now, not post-hoc mutation.
Unique materials
The cache halo and firewall slit own their emissive material, so they pulse per instance rather than in lockstep.
Connectors
Specimens exercise elbowCurve, arrowHead and dashedRun before the Phase 4 router is built on them.
